' --- Клиентские потоки в MDM ---
FU_CRM --> MDM_Client : Клиент\nCreate/Update (CDC)
RB_CRM --> MDM_Client : Клиент\nCreate/Update/Deduplicate (CDC)
MDM_Client --> ExtRegistry : Клиент\nValidate (sync API)
MDM_Client --> FU_Core : Клиент (golden id)\nRead/Enrich (batch/CDC)
MDM_Client --> RB_Core : Клиент (golden id)\nRead/Enrich (batch/CDC)
MDM_Client --> FU_Loans : Клиент (golden id)\nRead/Enrich
MDM_Client --> RB_Loans : Клиент (golden id)\nRead/Enrich
MDM_Client --> CaseSystem : Клиент (golden id)\nRead/Enrich

' --- Справочные потоки MDM ---
FU_CRM --> MDM_Ref : Продукт, Тариф, Отделение\nCreate/Update
RB_CRM --> MDM_Ref : Продукт, Тариф, Отделение\nCreate/Update
FU_Core --> MDM_Ref : Контрагент\nCreate
RB_Core --> MDM_Ref : Контрагент\nCreate
MDM_Ref --> FU_Core : Продукт, Тариф\nRead (batch/CDC)
MDM_Ref --> RB_Core : Продукт, Тариф\nRead (batch/CDC)
MDM_Ref --> FU_Cards : Тариф\nRead
MDM_Ref --> RB_Cards : Тариф\nRead

' --- Операционные потоки в аналитику ---
FU_Core --> DWH : Счёт, Транзакция\nAggregate (batch, ночной)
RB_Core --> DWH : Счёт, Транзакция\nAggregate (batch, ночной)
FU_Cards --> DWH : Карта, Транзакция\nAggregate (batch/CDC)
RB_Cards --> DWH : Карта, Транзакция\nAggregate (batch/CDC)
FU_Loans --> DWH : Кредит\nAggregate (batch)
RB_Loans --> DWH : Кредит\nAggregate (batch)

FU_Core --> Lakehouse : Транзакция, события\nCreate (streaming/CDC)
RB_Core --> Lakehouse : Транзакция, события\nCreate (streaming/CDC)

FU_Core --> Graph : Транзакция, Контрагент\nEnrich (streaming, real-time)
RB_Core --> Graph : Транзакция, Контрагент\nEnrich (streaming, real-time)
MDM_Ref --> Graph : Контрагент (эталон)\nRead

CaseSystem --> Search : Обращение клиента\nEnrich/Index (near real-time)

' --- Архивирование ---
FU_Core --> ObjStore : Договор, Счёт (закрытые)\nArchive/Delete из OLTP (batch, квартально)
RB_Core --> ObjStore : Договор, Счёт (закрытые)\nArchive/Delete из OLTP (batch, квартально)

' --- Отчётность и каталог ---

Lakehouse --> Catalog : Метаданные, lineage\nCreate/Update (scheduled scan)
MDM_Client --> Catalog : Метаданные золотой записи\nCreate/Update
MDM_Ref --> Catalog : Метаданные справочников\nCreate/Update
