# Владение данными

Для каждой сущности определены Data Owner (бизнес-владелец), Data Steward (ответственный за качество),
Producer (система/команда-создатель), Consumer (системы-потребители), правила изменения и обязательные
проверки качества.

## Клиент

| Роль | Значение |
|---|---|
| Data Owner | Розничный бизнес совместно с МСБ (по типу клиента) |
| Data Steward | Data Office |
| Producer | FU CRM, RB CRM (фронт-офис при онбординге) |
| Consumer | Core Banking, Cards, Loans, Контактный центр, BI, Риск-менеджмент |
| Правила изменения | Изменение ПДн клиента — только через CRM/MDM workflow с подтверждением клиента; прямое редактирование в DWH/Lakehouse запрещено |
| Правила качества | Обязательная валидация ИНН/СНИЛС/ОГРН по внешним реестрам (ФНС/ПФР) при создании; дедупликация перед публикацией золотой записи; контроль полноты KYC-полей |

## Счёт

| Роль | Значение |
|---|---|
| Data Owner | Розничный бизнес / МСБ (владелец продукта) |
| Data Steward | ИТ (команда Core Banking) |
| Producer | FU Core, RB Core |
| Consumer | Карты, Кредиты (ссудные счета), DWH, BI, Финансовый департамент |
| Правила изменения | Только через Core Banking, изменения баланса — исключительно через проводки, без прямых UPDATE |
| Правила качества | Сверка баланса с суммой проводок ежедневно; контроль уникальности номера счёта/IBAN |

## Карта

| Роль | Значение |
|---|---|
| Data Owner | Карточный бизнес (в составе Розничного бизнеса) |
| Data Steward | ИТ (команда карточного процессинга) |
| Producer | FU Cards, RB Cards |
| Consumer | DWH, BI, антифрод-система, контактный центр |
| Правила изменения | Только через карточный процессинг; статус карты меняется по регламентированным событиям (выпуск, блокировка, перевыпуск) |
| Правила качества | Соответствие PCI DSS (запрет хранения полного PAN/CVV вне процессинга); контроль соответствия карты активному счёту |

## Кредит

| Роль | Значение |
|---|---|
| Data Owner | Риск-менеджмент |
| Data Steward | ИТ (команда кредитной системы) |
| Producer | FU Loans, RB Loans |
| Consumer | Финансовый департамент (резервы, отчётность), DWH, BI |
| Правила изменения | Изменение статуса и графика — только кредитной системой по регламентированным событиям (просрочка, реструктуризация) |
| Правила качества | Единые правила расчёта просрочки и дефолта (маппинг между FU/RB на переходный период); контроль соответствия суммы выдачи и графика платежей |

## Договор

| Роль | Значение |
|---|---|
| Data Owner | Юридический блок совместно с продуктовым бизнес-подразделением |
| Data Steward | Data Office |
| Producer | CRM/Core в момент подписания |
| Consumer | Счёт, Кредит, Карта (как основание), аудит, комплаенс |
| Правила изменения | Изменение статуса договора — только через регламентированный процесс (расторжение, пролонгация), содержимое подписанного документа неизменяемо |
| Правила качества | Обязательное наличие скан-копии/электронной подписи; уникальность номера договора |

## Транзакция

| Роль | Значение |
|---|---|
| Data Owner | Финансовый департамент совместно с Core Banking |
| Data Steward | ИТ |
| Producer | FU Core, RB Core, FU Cards, RB Cards |
| Consumer | DWH, Data Lakehouse, антифрод, BI, регулятор (через отчётность) |
| Правила изменения | Транзакция неизменяема после фиксации (append-only); корректировки — только новой компенсирующей записью |
| Правила качества | Контроль баланса дебет/кредит; исключение дублей при параллельной работе FU/RB систем в переходный период |

## Платёж

| Роль | Значение |
|---|---|
| Data Owner | Финансовый департамент совместно с Комплаенс/AML |
| Data Steward | ИТ + Комплаенс |
| Producer | Core Banking, платёжные шлюзы |
| Consumer | AML-мониторинг, DWH, регулятор |
| Правила изменения | Статус платежа меняется только платёжной системой по результатам исполнения; ручные правки запрещены |
| Правила качества | Обязательный AML/санкционный скрининг до перевода в статус "исполнен"; контроль полноты реквизитов получателя |

## Продукт

| Роль | Значение |
|---|---|
| Data Owner | Product Management (Розница/МСБ) |
| Data Steward | Data Office |
| Producer | Product Management через CRM/Core (конфигурация) |
| Consumer | Все продуктовые системы (Core, Cards, Loans), CRM, BI |
| Правила изменения | Изменение — только через процесс согласования product-команды, с версионированием |
| Правила качества | Уникальность кода продукта; проверка актуальности условий перед публикацией в MDM |

## Обращение клиента

| Роль | Значение |
|---|---|
| Data Owner | Контактный центр |
| Data Steward | Data Office |
| Producer | CRM/Case-система при регистрации обращения |
| Consumer | BI, Product Management (анализ жалоб), Риск-менеджмент (жалобы по мошенничеству) |
| Правила изменения | Изменение статуса — только оператором/системой Case-менеджмента в рамках SLA |
| Правила качества | Обязательная привязка к client_id (после матчинга в MDM); контроль соблюдения SLA по срокам ответа |

## Отделение

| Роль | Значение |
|---|---|
| Data Owner | Розничная сеть / административный блок |
| Data Steward | Data Office |
| Producer | CRM (регистрация точки обслуживания) |
| Consumer | Договор (место заключения), региональная отчётность |
| Правила изменения | Только через административный процесс открытия/закрытия отделения |
| Правила качества | Единый справочник регионов/адресов, отсутствие дублей кодов отделений |

## Тариф

| Роль | Значение |
|---|---|
| Data Owner | Product Management |
| Data Steward | Data Office |
| Producer | Product Management через CRM/Core |
| Consumer | Карта, Счёт, Кредит |
| Правила изменения | Изменение тарифа — только через согласованный процесс с указанием периода действия (без перезаписи истории) |
| Правила качества | Отсутствие пересечения периодов действия тарифов для одного продукта; обязательная привязка к product_id |

## Контрагент

| Роль | Значение |
|---|---|
| Data Owner | Риск-менеджмент / Комплаенс |
| Data Steward | Data Office |
| Producer | Core Banking (при регистрации операции с новым контрагентом) |
| Consumer | Антифрод (графовая БД), Платёж, Кредит (поручители) |
| Правила изменения | Обновление реквизитов — только через верификацию по внешним источникам (БИК-справочник ЦБ, ЕГРЮЛ) |
| Правила качества | Обязательная сверка с санкционными/стоп-листами; контроль формата ИНН/БИК |
